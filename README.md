# favia (alpha)

favia is a Fast Video App for Linux based on ffmpeg and SDL.


## Features & limitations

* Play video files with hardware decoding (VAAPI/Linux); limited range of supported formats, no support for multiple streams, no subtitles


## Control Keys

| Key | Action |
| --- | --- |
| `q`          | Quit |
| `Space`      | Pause/Resume |
| `[Ctrl+]Left/Right` | Seek |
| `+/-`        | Zoom |
| `f`          | Fullscreen |


## Build for Linux

```sh
bash xbuild-debianBW.sh
```
